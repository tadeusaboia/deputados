📊 BI Parlamentar — Painel Analítico de Gastos (2025 – 2026)

Painel interativo de Business Intelligence (BI) desenvolvido em HTML, Tailwind CSS e D3.js que consome em tempo real a API de Dados Abertos da Câmara dos Deputados para analisar os gastos da Cota para o Exercício da Atividade Parlamentar (CEAP).

✨ Funcionalidades

Dashboard Analítico (BI):

4 KPIs Executivos: Gasto Total no Período, Média Mensal, Ticket Médio por Nota e Concentração na Maior Categoria.

Evolução Mensal Comparativa (D3.js): Gráfico de barras agrupadas comparando mês a mês os gastos de 2025 vs 2026.

Filtro Cruzado (Cross-Filtering): Clique em qualquer barra de categoria para filtrar dinamicamente os fornecedores, indicadores e notas fiscais.

Top 5 Fornecedores e Drill-Through: Lista das empresas mais contratadas e tabela completa com link direto para o PDF de cada nota fiscal.

Top 10 Maiores Gastos: Ranking ordenado do maior para o menor gasto por bancada estadual ou amostra nacional.

Bancada por Estado: Listagem de todos os deputados federais por UF com filtro instantâneo por nome ou partido.

🚀 Como publicar este projeto no GitHub Pages

Crie um repositório no GitHub:

Acesse github.com/new, dê um nome ao repositório (ex.: bi-parlamentar), deixe como Public e clique em Create repository.

Envie os arquivos:

Clique em uploading an existing file e envie o arquivo index.html (e este README.md, se desejar).

Clique em Commit changes.

Ative o GitHub Pages:

No repositório, acesse a aba Settings (Configurações) > Pages (no menu lateral esquerdo).

Em Build and deployment > Source, selecione Deploy from a branch.

Em Branch, escolha main e a pasta / (root), depois clique em Save.

Acesse o seu site:

Após cerca de 1 minuto, o GitHub exibirá o link público no topo da página no formato:
https://seu-usuario.github.io/bi-parlamentar/
